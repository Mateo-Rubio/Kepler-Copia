#
# Diseño:
#  - 4 ejemplos que cubren 4 de las 5 franjas diurnas (se omite una
#    a propósito para poder observar generalización, no copia).
#  - Cada ejemplo contiene el token ancla literal exigido por la
#    regex del validador (morning | mid-day | afternoon | evening |
#    overnight). Sin el token literal la extracción falla y cae al
#    fallback silencioso.
#  - Los ejemplos son UN SOLO PARRAFO, sin saludo ni firma. Esto
#    ataca implicitamente el fallo de registro de qwen2:7b
#    ([Your Name], 151/161 de sus artefactos) sin necesidad de una
#    instruccion explicita que confundiria el experimento.
# ================================================================



# ================================================================
# CHAIN-OF-THOUGHT — razonamiento explicito antes de redactar.
#
# Nota de implementacion: el parser actual de generator.py es
#   r"\x60{3}(?:prompt|text)?\s*(.*?)\s*\x60{3}"
# y extrae el PRIMER bloque delimitado. Por eso el razonamiento va
# en prosa plana FUERA del bloque y la solicitud final dentro. No
# hace falta tocar el parser. Es critico instruir que el
# razonamiento nunca use delimitadores de bloque, o el parser
# extraeria el razonamiento en lugar de la solicitud.
# ================================================================

# ================================================================
# PROMPT CHAINING — dos llamadas secuenciales.
#
# Llamada 1: resuelve SOLO la expresion temporal.
# Llamada 2: recibe esa expresion ya verificada como insumo fijo y
#            NO recibe target_day / target_diurnal_period en crudo,
#            para que no pueda re-derivarlas. Ese aislamiento es lo
#            que hace que la estrategia sea distinta de zero-shot.
# ================================================================
